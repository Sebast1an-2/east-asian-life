# V0.2 阶段3：青年人生分流

保留28个旧事件，新增22个候选，总数50。正式成年育儿、中年和晚年内容未开发。
年龄区间包含两端；候选不保证一局全部发生。重要节点仍最多每年3件。
新增数据在 events-young.js；原有事件在 events.js。

婚姻讨论只发生一次，不对主动不婚的人反复催促，不作为同年追加节点。

分手后即时状态为single，不继续遇到依赖dating/married的事件。
不创建伴侣NPC；所有文案都只描述当下关系，不假装知道未记录的过去。

## 三条已接通的青年链

- 工作：原第一份工作 → 高压机会/平衡晚上 → 晋升、倦怠或调岗 → 中途换节奏。
  暂缓毕业方向 → 求职准备/普通工作；裁员补偿 → 待业 → 求职。
- 关系：相遇 → 恋爱/单身 → 日历协商 → 登记/不登记/分开。
  单身可以重新开放相遇，不婚伴侣可以继续生活，也可以重新选择登记。
- 居住：与家人同住 → 留家/租住 → 租金安排 → 买房/继续租。
  买房有修理后续，也可以回租住；租房可以主动重开讨论，不强制买房。

重要标签包括争取晋升、暂缓晋升、选择单身、愿意谈未来、主动不婚、
已讨论住房、主动不生育等；均与状态、条件或后续选择共同使用。
个别日常记录标签仅作为未来内容入口，不声称已有额外隐藏效果。

## 实际两局例子（同一随机种子3）

两局学生时代选择相同，23岁及成年选择策略不同。以下来自真实年度引擎：

| 年龄 | 高压事业、偏购房 | 平衡工作、偏单身租住 |
|---|---|---|
| 23 | 高收入高压工作 | 稳定普通工作，workStyle为balanced |
| 25 | 被看见的代价：接急项目 | 工资保管回声 |
| 27 | 晋升谈话：接受 | 职场排名回声：选择自己的尺度 |
| 29 | 春节回家 | 搬出讨论：租住 |
| 31 | 搬出讨论：租住 | 工作调整：边界清楚的岗位 |
| 33 | 住房讨论：买房 | 下班后的个人生活 |
| 34 | 工作倦怠 | 春节安排 |

这是不同经历，不是更好/更差；高压也可以通过急项目、倦怠、调岗转向。
此外定向测试中，同样处于29岁租房、余额6000，选择买房会在30岁进入修理候选，
继续租则仍在租金候选里；两种状态互相排除对应专属事件。

## 检查与范围

- 原8/28个事件及阶段1/2回归测试保留，另测完整50个事件的页面与刷新。
- 240轮随机完整人生确认50个候选都至少实际触发一次。
- 4组选择策略各60轮，从出生到80岁；22～35岁最长连续空白0年。
- 10组明确当前状态各8轮，从24岁到80岁，包括单身、已婚无孩子、不婚伴侣、明确不生育、
  高压、平衡、低预算待业、低预算租房、自有住房且有孩子，以及旧stable值。
  24～35岁最长连续空白不超过1年。
- 这不是对所有可能组合的穷举，也不保证每年必须发生剧情。

质量修正取消上述五个事件的Major标记，保留原分类及priority，不增加剧情。
窗口调整是为了接住晚进入事业、独立、关系和住房选择的人，不是把事件错开。
搬出最晚35岁，独立回声到36岁，仅为现有链留下一年的后续机会。
协商婚后共同生活是生育讨论的前置经历，不代表玩家承诺生育。
Validation 零格式/引用错误；正式库目前零警告，原8条来自这五个Major标记。
检查器仍保留重叠审查提醒，文案明确“不一定是错误”，不做条件互斥静态分析。
测试继续构造合理重叠及超上限节点验证提醒，年度上限和刷新机制保持原规则。
已经展示的旧卡片取消Major后，若仍符合条件，可恢复并完成；新追加仍只抽Major。
若新保护让旧的未选讨论失效，恢复时仅撤下卡片，保留人物、历史和年度计数，
不重抽普通事件；结构损坏、未知事件等异常存档仍拒绝恢复且不覆盖原内容。

唯一状态值补充是balanced：边界清楚的普通工作。旧stable值仍能校验和恢复，
旧历史不改写；格式version仍为3。本次沿用条件对象，小幅补充historyChoicesAny
（多个具体历史选择满足一个即可）和statesNone（排除完全匹配的一组当前状态），
并复用现有字段/引用校验；没有复杂规则语言或第二套条件系统。
原第一份工作steady从现在开始记录balanced，文案、标签和属性不变；
另加暂缓进入职场的排除标签，让毕业方向选择真的生效。
