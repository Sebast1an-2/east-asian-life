# 事件清单：28 个事件

保留原有 8 个事件，新增 20 个。标记「原」表示原有事件。
年龄范围包含两端，是允许发生的窗口，不保证每局都会发生。
每年仍只有一个事件：必然节点优先，其次后续、条件、随机。
下表标签按不同选择列出，不会一次全部添加；「—」表示不添加。
标签条件实际字段为 tagsAll，历史条件为 historyEventIds；
不使用引擎尚未支持的 requiredTags 或 requiredHistoryEvents。

## 已接通的跨年龄事件链

- A：3～4 岁留下旧画册 → 13 岁选择兴趣或成绩 → 28～32 岁重看蓝色太阳。
  成年后无论继续或放下过画画，都有重新选择的机会；缺少旧画册则不触发。
- B：12～14 岁商量手机与联系 → 23 岁工作 → 24～28 岁面对老板深夜消息。
  回应任务会移除「保留离线时间」，商量明早处理会移除「习惯随时回应」。
- C：9～12 岁回答亲戚 → 19 岁选择专业 → 24～27 岁再次面对饭桌期待。
  真实回答会移除过去的「熟悉标准答案」。
- D：7～10 岁商量压岁钱 → 23 岁工作 → 26～30 岁自己给家人准备礼物。
  说明预算会移除「钱交家里保管」。
- E（原有）：8 岁95分 → 21～22 岁翻到旧试卷。

这些关联通过实际标签和历史条件触发，不只是文案中提及过去。
尚未接通专属后续的标签只是未来写剧情的入口，不声称已经有隐藏效果。

## 检查

运行 `node tests.cjs`：保留首批 8 个事件的回归测试，再检查完整 28 个事件。
新增测试使用 160 个固定随机种子的真实人生、不同选择，从出生推进到终点，
确认每个事件至少被实际选中过一次，检查后续事件有较早的前置历史，
并检查每年的存档状态及完整事件库的刷新恢复。
可触发不代表每局必出，也不代表所有组合都已穷举测试。
